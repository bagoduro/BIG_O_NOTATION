🚀 COMO USAR
═════════════════════════════════════════════════════════════════════════════════

1. Clonar o repositório:
   
   git clone https://github.com/bagoduro/BIG_O_NOTATION.git
   cd BIG_O_NOTATION

2. Compilar os exercícios:
   
   cd src
   javac *.java

   OU (no Windows):
   compilar.bat

3. Executar cada exercício:
   
   java Exercicio1
   java Exercicio2
   java Exercicio3
   ... (continue com os demais)

4. Ler a documentação:
   
   • README.md - Guia principal
   • docs/SUMARIO_RAPIDO.txt - Visão geral
   • docs/VISUALIZACAO_COMPLEXIDADES.txt - Gráficos

🎯 RESUMO DOS 10 EXERCÍCIOS
═════════════════════════════════════════════════════════════════════════════════

1. Busca Linear                  → O(n)
2. Busca Binária Recursiva       → O(log n)
3. Bubble Sort Otimizado         → O(n²)
4. Selection Sort                → O(n²)
5. QuickSort com Pivô Fixo       → O(n²)
6. Merge Sort                    → O(n log n)
7. Fibonacci Recursivo vs DP     → O(2ⁿ) vs O(n) ⭐
8. Verificação de Palíndromo     → O(n)
9. Busca de Padrão               → O(n·m)
10. DFS e BFS em Grafos          → O(V+E)
