EXERCÍCIO 1: BUSCA LINEAR COM CONTAGEM
├─ Implementação: ✅ Procura valor em vetor, conta comparações
├─ Pior Caso: Elemento inexistente ou última posição
├─ Complexidade: O(n)
├─ Resultado: Posição + número de comparações
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 2: BUSCA BINÁRIA RECURSIVA  
├─ Implementação: ✅ Busca recursiva em vetor ORDENADO
├─ Pior Caso: Elemento não existe no vetor
├─ Complexidade: O(log n)
├─ Resultado: Índice + iterações
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 3: BUBBLE SORT OTIMIZADO
├─ Implementação: ✅ Bubble sort com flag de parada
├─ Melhor Caso: O(n) - vetor já ordenado
├─ Pior Caso: O(n²) - vetor em ordem decrescente
├─ Resultado: Comparações, trocas, iterações
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 4: SELECTION SORT
├─ Implementação: ✅ Selection sort com contagem
├─ Complexidade: O(n²) - SEMPRE, independente da entrada
├─ Comparações: Sempre n(n-1)/2
├─ Trocas: Varia de 0 a n-1
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 5: QUICKSORT COM PIVÔ FIXO
├─ Implementação: ✅ QuickSort com primeiro elemento como pivô
├─ Melhor Caso: O(n log n) - partições balanceadas
├─ Pior Caso: O(n²) - vetor já ordenado
├─ Causa: Pivô fixo causa divisões desbalanceadas
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 6: MERGE SORT
├─ Implementação: ✅ Merge sort com contagem de operações
├─ Complexidade: O(n log n) - SEMPRE, em todos os casos
├─ Espaço: O(n) - usa arrays auxiliares
├─ Vantagem: Desempenho previsível
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 7: FIBONACCI RECURSIVO vs DP ⭐ DESTAQUE
├─ Versão 1 - Recursivo Simples: O(2ⁿ) - EXPONENCIAL
│  └─ fib(35) = 29.860.703 chamadas = 154ms ❌ MUITO LENTO
├─ Versão 2 - Com Memoização: O(n)
│  └─ fib(35) = 69 chamadas = <1ms ✅ MUITO RÁPIDO
├─ Versão 3 - Tabulação (Bottom-up): O(n)
│  └─ fib(35) = 34 operações = <1ms ✅ MAIS EFICIENTE
├─ Ganho de Desempenho: 1500x mais rápido com DP!
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 8: VERIFICAÇÃO DE PALÍNDROMO
├─ Implementação: ✅ Verifica caractere a caractere
├─ Melhor Caso: O(1) - falha na primeira comparação
├─ Pior Caso: O(n) - todos os caracteres são iguais
├─ Versões: Básica + com ignoração de espaços/maiúsculas
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 9: SUBSTRING POR FORÇA BRUTA
├─ Implementação: ✅ Busca de padrão usando força bruta
├─ Complexidade: O(n · m)
│  └─ n = tamanho do texto, m = tamanho do padrão
├─ Pior Caso: Falha no último caractere, repetidamente
├─ Exemplo: "AAAAAAAAAB" procurando "AAAB" = 28 comparações
└─ Status: COMPILADO E TESTADO

EXERCÍCIO 10: PERCURSO EM GRAFO
├─ Algoritmos: DFS (profundidade) e BFS (largura)
├─ Complexidade: O(V + E)
│  └─ V = vértices, E = arestas
├─ Recursos: Conectividade, contagem de componentes
├─ Representação: Lista de adjacência
└─ Status: COMPILADO E TESTADO
