💡 CONCEITOS-CHAVE APRENDIDOS
═════════════════════════════

1. ANÁLISE ASSINTÓTICA
   → Entender como os algoritmos escalam com a entrada
   → Focar no pior caso para garantir bom desempenho

2. TRADE-OFFS
   → Tempo vs Espaço (Merge Sort usa mais memória)
   → Simplicidade vs Eficiência (Bubble Sort vs QuickSort)

3. OTIMIZAÇÕES
   → Flag no Bubble Sort reduz iterações
   → Memoização transforma O(2ⁿ) em O(n)
   → Boas estruturas de dados aceleram algoritmos

4. PADRÕES
   → Loops aninhados → O(n²)
   → Divisão e conquista → O(n log n)
   → Recursão sem otimização → Exponencial
